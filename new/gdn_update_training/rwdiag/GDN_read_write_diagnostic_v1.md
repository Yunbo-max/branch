# GDN 记忆诊断：读错、写错，还是后来被干扰？

**性质：实验设计，不是运行报告。** 基线为原始 `puigde/gated-deltanet-360M-15B-slimpajama`，优先复用 `Yunbo-max/branch` 的 `426f75e` 代码；不能用已在这些测试上调整过的模型充当冻结基线。主实验不训练新主干，不增加部署时的记忆。以下是建议预注册的设置，可以在看确认集前修改并锁定。

## 1. 预先区分的解释

- R：前缀状态仍含“实体—版本—值”的绑定，但原生查询没有有效利用它。
- W：该绑定在写入结束时就难以使用。K（地址）、β（强度）、V（写入内容）均为候选，不预设是 V 的错。
- F：写完能使用，但在后来的记录或填充中衰减或受到干扰。
- R×W / 其他：修复读写两侧才有效，或证据只支持下游读出器的问题，或现有探针/干预太弱。不能强行三选一。

## 2. 样本单位和无捷径对照

1. 一个独立场景使用随机无语义实体名，生成两段成对的历史。两段初始值相同，交换 X、Y 的最终赋值；末尾再写 Z，且 Z 的值与 X 独立。两段的实体、值的多重集合、长度、顺序框架、问题文本一致。一起测试 X 当前、Y 当前、X 最初、Z 当前。X/Y 的位置平衡；增加一批固定实体/数值多重集合、只交换同一实体两次写入顺序的样本，防止靠值是否出现过作答。
2. 正例/空对照：用中性等长 token 取代 X 的旧记录（仅新值）；重复到同一值；没有 X 的有效记录；无关实体和同一实体的重复写入分开。四个值的 12 个异值有序转换平衡；另外保留 4 个不变转换。在独立抽值、未条件化的四类面板才把 25% 当作随机基线；对交换不同值、终值必须不同于初值等条件化面板，使用组内匹配的置换基线，并报告类别频率。
3. 同一场景全部变体、所有距离、所有问题必须在同一划分。建议 1,920 个训练场景、240 个开发场景、480 个确认场景作为起始规模，并根据开发集的配对离散度在揭盲前核定精度。训练诊断读出器的实体/模板与确认集隔离。种子、分割和模板固定并入清单。数据 seed、probe 训练 seed 和模型 checkpoint 是三种不同的重复单位。
4. 取样点：X 更新前、完整 X 更新记录结束、无关赋值结束、再添加中性文本/无关实体写入后且尚未提问。记录“目标记录结束→问题开始”的实际 token 距离；将没有中间事件的立即读和有后续无关事件的条件分开。首轮在配置窗口 2,048 内；固定事实和更新次数改变距离，在同距离比较中性填充与无关写入。4K/8K 独立标明为窗口外推。不能用总长度代表遗忘距离。

## 3. 冻结状态，可解码性与 Q-only 是两项不同测试

- 在提问前复制每个候选层/头的矩阵 S。整个模型冻结；离线 probe 只接收 S 和仅含实体名/版本/问题、不含答案与历史的编码。一个小型可实现的读出是，对预选头做 S_h q_phi(question)，拼接后用共享线性四类头解码。不得让 question encoder 看到历史隐藏表示、生成 seed、样本 ID、gold 等。只从训练集拟合，开发集选少量层/头及容量；同一已锁定读出器跨时间点使用，并另做时间点内匹配训练的容量敏感性对照，避免把表征漂移直接称为删除。
- 必须通过：仅新值阳性、去状态、只给问题、乱配同模板不同答案的状态、训练标签置换；另外固定问题，在成对历史间交换 S，观察答案是否跟随供体的实体绑定。报告 X/Y 是否都能按绑定翻转，避免仅解码“最近见过某个字母”。这些测试证明的是给定读取器可恢复信息，不自动说明主模型使用它。
- Q-only 因果实验：在预测答案的最后一个提示 token，使用同一层/头**同一个读出时刻**的原生 S，只换归一化 q 的方向。保留该层原生 K/V/α/β、原生缩放、输出门、输出投影、残差与 LM head；不插入新的分类器。替代 q 可由只见问题的低秩映射在 train 上用冻结模型真实输出训练。另设相同参数量的 query-only 无 S 控制、等幅随机方向、状态互换对照；用另一问题种子/错误实体作负对照。禁止用测试标签逐样本优化 q，禁止用含正确值的供体 q 当作主要证据。
- 前缀 S 与最终答案位置的 S 不是同一个：问题 token 也会写入状态。对前缀截断读出和最终 Q-only 分别报告。端到端重放从同一个前缀缓存副本开始（包括短卷积缓存）；做层内替换时，其他输入按原轨迹固定。上层自然响应与层内固定轨迹重放不要混报。若只改后置分类器能救结果，而 Q-only 不能，只记为“可解码、原生读出路径未定位”。

## 4. 固定原始读法，拆分写侧

- R0W0：原生行为。R1W0：只换 q。R0W1：只改指定更新 span 的写入，保留原生读法。R1W1：相同写法加相同替代 q。这里 W1 首先是 *单一* 干预，分别对 K-only、β-only、V-only 运行小网格，不能把三项捆成一个机制结论。
- 先用相同训练/验证协议选择干预层、头和位置范围；包括值 token、记录终止符、记录 span，不把最后一个值 token 自动当作唯一写入点。先查分层结果和小组头，正负结果要限定在干预的范围。等容量校准器，配对相同样本，约束方向角度、向量范数或门控范围，并设置等幅随机扰动和错误 span。用与原始值语义无关的密钥/问题禁止传递 gold。
- K-only：用仅从实体标识和属性得到、开发集已经锁定的方向作校准，保留当前写入值/门控，同时替换 Delta 更新内部读旧值及写回使用的同一个 K。β-only：在开发集选择固定门控偏移/强度，保留 K/V/α。V-only：在同一位置以格式和位置匹配、含同一条显式输入值但无旧值冲突的参考记录提取 V；保持接收方 K/β 不变。V 供体本身携带输入值，所以只作为“内容替换能否救读出”的诊断，不是证明原 V 不含信息或部署方法；用错误值供体检查输出是否随之翻转。可以另测有限容量、只用历史输入的 V 校准器。
- 写侧改动可能自然改变更高层的 q。严格 R0 的局部版本钳制回基线对应读位置的 q，另报下游自然演化结果。所有条件都用同一原生 LM head 重新评分。需要时把原生 S 清除/换成匹配对照，记录干预收益是否仍然存在，排除残差等旁路解释。保持同一干预 site 与额外参数预算；正向救援表明一种干预足以改善，不证明它是唯一或必要原因。
- 内容被“混合”的证据应比只看 V 的余弦更强：固定 X 最终值和查询，只改变其他实体的写入值。如果 X 的预测系统性跟着别的实体值变化（并且等长中性文本没有同样效果），再比较干预 K、V 或 β 后这种串扰是否下降。无正作用不等于信息论意义上的不存在。

## 5. 先过工程关，再解释效果

分段前缀+后缀重放 vs 原始整段 forward；无改动 tap vs 无 tap；匹配层内状态重建 vs 原生输出；自交换和设为原向量的干预必须还原基线。原精度、输出门、头缩放、有效 token、卷积状态保持一致。用 FP32 最小例找索引/转置错误；BF16 用事先校准的 logit 容差并单列近似并列的 argmax，不能默认 bitwise 相等。测试的真实值和实体对应关系不得经供体键或 probe 的元数据旁路进入答案。

## 6. 指标、表格与决定

主指标：同一个交换对的两段历史都答对 X 当前值的比例；并报 Y 当前、历史、保护实体及 4 项同时正确。辅助指标为普通准确率、已改变样本中预测初值的比例、预测其他实体值的可识别串扰率（仅在新值、旧值、干扰值可区分的子集），以及新值减旧值的 logit 差。成功率不能仅在原始错误上报；同列原错救回和原对改错数。用场景做配对 cluster bootstrap，整个场景的所有变体一起重抽，报告 95% 区间；确认集一次性评估，不在上面选层或挑成功案例。

预定义四格分数 P00/P10/P01/P11：Q 效应=P10−P00，W 效应=P01−P00，交互=P11−P10−P01+P00。每种 W 分别计算；独立读出器的准确率不混入四格。可预设 +5 pp 为实际关注的救援量，保护题最多可接受损失和区间规则事先约定；证据不足则报告不确定，不能靠‘不显著’宣布等效。

判读：前缀可解码且 Q-only 稳定救回 → 优先读侧；立即可读、延迟后下滑 → 保留/后续干扰；R0 下 K/β/V 单项救回 → 具体写入因素候选；正结果只见于 R1W1 → 读写接口匹配；所有方法均失败 → 此探针/干预族未定位，不等于信息不存在。若要主张 GDN 特异性，加能力匹配 Transformer 与另一纯 GDN checkpoint，先对齐短程序列的无冲突能力。
