# 读写诊断的终点：一次独立确认，然后设计方法

本轮只选一个低成本方法原型，不证明整个 GDN 家族的能力上限。旧的 v2 pilot 仍有效；不修改 `rwdiag/` 的源文件、读出器或已有结果。

## 一次执行

在已经分配的 GPU 上，完成同一分支的 binding-v2 pilot 后，从仓库根目录执行 `python new/gdn_update_training/finish_rwdiag.py`。默认从标准路径自动寻找唯一有 `dev/decision.json` 的 pilot；非默认目录或有多个时显式传 `--pilot /absolute/path/to/pilot_...`。`--plan` 只打印计划，不加载模型。没有完成的 pilot 才运行 `bash new/gdn_update_training/run_rwdiag.sh pilot`。无需单独跑 retention、三臂训练或重新 fit。锁文件和结果在该 pilot 的 `design_confirmation/`；同一个目录不能覆盖。没有 GPU 测量包含在本提交中。

在打开 test 之前只能指定一个主候选，默认 q（最初的寻址假设）。若开发集促使变更，只能在揭盲前用 `--candidate k|beta|v|q+k|q+beta|q+v` 选一个；不能对同一批 test 逐个挑赢家。层、头、读出器、beta、写入位置和 checkpoint 沿用开发实验。仅支持已有的 value-span 负对照。runner 会执行原生数值一致性检查、训练/测试隔离与身份检查，并拒绝超出模型配置的上下文。脚本只做评估，不提交调度作业。

48 个独立测试场景、六面板、两世界，两种更新顺序已包括在六面板中。X/Y 当前值、X 最早值和 Z 当前值四问；刚写完、其他实体写完、中性文本或其他记录后两个间隔（128 / 1024 填充 tokens）。合计 13,824 基础问题行，每行有多次原生前向；不是 13,824 个独立样本，也不是一个廉价的 smoke。正式论文不能据此声称多 checkpoint、无限上下文或整网唯一根因。

## 固定判据

主指标：只改 X 新值、其余历史固定的场景中，在加入 1024 tokens 其他记录后，`x_now` 的准确率差。每个场景先平均两个世界与两个顺序再做配对 bootstrap。原生基线为相同样本。预先选定的干预相对原生收益至少 +5 个百分点且 95% 区间下界 >0；相对预设特异性对照下界 >0（Q 对等幅随机方向、K 对随机方向、beta 对错误位置、V 对错误值，联合干预对两个单项）。在同一条件下 `y_now`、`x_first`、`z_now` 分别与原生对比，区间下界都须 > -5 个百分点。阈值是原型选择的工程标准，不是已知效应或功效保证。联合全对率、救回与弄错的样本、读出器的状态互换/零状态/乱标签/只看问题、最早时刻和其他长度均保留为解释证据；不要把 probe 能读出等同为模型使用该路径。

## 跑完后的选择

- 主候选通过：优先开发这一干预对应的因果可用版本。Q → 查询/版本寻址训练；K → 稳定写地址；beta → 选择性写入强度；V → 训练时内容绑定监督，不把提供正确值的 donor 当成推理方法；Q+W → 联合协调并与两个单项对照。
- 其他分组只作为探索线索：仅改 Y 时 X 的预测跟随实际 Y 而非配对世界的 Y，同时等距离记录比中性文本更差，可提出等总字节的写入隔离或固定槽 Branch。只有中性 1024 比 128 更差则提示保留或读出随距离漂移，不等于 alpha 有问题。资格分母和配对区间写入 `secondary_patterns`；这些不是第二次确认机会。
- 合格运行后不再补统一诊断网格。主候选不过或区间太宽就转入同数据 SFT 对照下的行为级反事实更新训练；不把不显著解释成不存在信息，也不追换层/头/种子直到显著。若有强探索性线索，可把它作为新原型的假说而不是已确认机制。若工程资格失败，修复技术错误，不把错误日志当作科学结果。
- 原型保留固定状态；与同样本、同可训练参数的 SFT 对照。实际部署再分别测 prefill、decode 和每序列缓存字节；本诊断的串行重放速度不是推理速度。

最终交付 `design_confirmation/route.json`：主候选结论、相对基线/匹配控制的区间、三项保护题差值、串扰和保留的探索线索。`design_confirmation/test/decision.json` 及 `summary.json` 保存其他分组和所有干预。
