# Evaluation protocol

Mirrors paper §4.1. Three suites; only the first is wired to a vendored harness.

## 1. Commonsense (Table 1) — 8 zero-shot tasks

| key | task | metric |
|---|---|---|
| LMB. | `lambada_openai` | acc |
| PIQA | `piqa` | acc |
| Hella. | `hellaswag` | acc |
| Wino. | `winogrande` | acc |
| ARC-e | `arc_easy` | acc_n |
| ARC-c | `arc_challenge` | acc_n |
| OBQA | `openbookqa` | acc_n |
| CSQA | `commonsense_qa` | acc |

Harness: vendored **lm-evaluation-harness** at
`code/log-linear-attention/flame/3rdparty/lm-evaluation-harness`.

```bash
bash eval/run_commonsense.sh <checkpoint-or-hf-dir>
```

Note: `MARCHModel` in `code/march/` is a plain `nn.Module`, not an HF `PreTrainedModel`.
To use lm-eval you must either (a) wrap it in an HF-compatible class, or (b) export logits
through the harness's custom-model API. This is the first integration task.

## 2. LongBench (Table 2) — 12 tasks

Single-Doc QA: `narrativeqa`, `qasper`, `multifieldqa_en`
Multi-Doc QA: `hotpotqa`, `2wikimultihopqa`, `musique`
Summarization: `gov_report`, `qmsum`, `multi_news`
Few-shot: `trec`, `triviaqa`, `samsum`

Toolkit cloned at `code/LongBench` (`THUDM/LongBench`). Use its per-task metrics
(F1 / ROUGE-L / accuracy). Max input length follows LongBench's defaults; the paper does not
report per-task truncation, so state your choice explicitly when comparing.

```bash
python code/LongBench/pred.py --model <model> --task narrativeqa qasper ...
python code/LongBench/eval.py --pred <pred-dir> --dataset longbench --results <out.json>
```

`MARCHModel` needs a `pred.py` adapter (tokenizer + generate loop). Not yet written.

## 3. RULER NIAH — 6 tasks x {4K, 8K, 16K} (+32K extrapolation)

Tasks: `s_niah_1`, `s_niah_2`, `s_niah_3`, `mk_niah_1`, `mq_niah`, `mv_niah`.

RULER data is **synthetic**, generated by `code/RULER` (`NVIDIA/RULER`) — there is no static
download. Generation needs the model's tokenizer:

```bash
cd code/RULER/scripts
python data/prepare.py --save_dir <out> --task <task> --tokenizer_path <tok> --max_seq_length 16384
```

Then score with `code/RULER/scripts/eval/*.py`. Paper reports 4K–32K in Figure 3, with the
models trained at 16K, so 32K is zero-shot length extrapolation.

## 4. In-context retrieval

SQuAD, TriviaQA, SWDE, FDA, Natural Questions. The first two and NQ are fetched by
`data/fetch_eval.py --groups retrieval`; **SWDE and FDA are not on the Hub** and must be
obtained from their original sources (SWDE: structured-web extraction benchmark; FDA: from
the In-Context Learning demonstration papers). No scoring script is bundled yet.

## What is *not* reproducible from this tree

- The paper's fused producer–reader Triton kernel (throughput numbers in Figure 4).
- Any absolute number, until a 50B-token pretraining run is completed for each model.
